# Logic Circuit Simulator

An interactive logic circuit simulator built in C++ using the [SplashKit](https://splashkit.io/) framework. Design and simulate digital logic circuits with drag-and-drop gates, wires, and more!

---

## Features

- **7 Gate Types**: AND, OR, NOT, NAND, NOR, XOR, XNOR
- **Circuit I/O**: Place gates, pins, wires, and rename them!
- **Real-time Simulation**: Toggle your inputs and the outputs will follow!
- **Adjustable Settings**: Don't like some settings? There's plenty to change :D
- **Background Music & SFX**: Ambient music and UI click sounds included... because what else is better when dealing with electricity.

---

## Installation

Go to the [Releases](../../releases) page and download the latest zip for your platform:
- `LogicCircuitSimulator-*-windows.zip` - Windows
- `LogicCircuitSimulator-*-macos.zip` - macOS

Unzip it anywhere and run `Logic_Circuit_Simulator.exe` from inside the unzipped folder. No installation or dependencies required.
